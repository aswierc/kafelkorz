# Zapis projektu jest niezależny od edytora

MVP automatycznie zapisuje w przeglądarce wiele projektów z teksturami i pozwala między nimi przechodzić. Edytor korzysta ze wspólnego kontraktu dostępu do projektów, a wersjonowany format nadaje projektom oraz teksturom stałe identyfikatory. Późniejszy zapis serwerowy może wykorzystać ten sam model projektu i obliczenia geometrii.
